# Intima — Telegram-бот

Цифровий помічник для сексуального здоров’я та близькості в парі (мінімальний прототип).

## Про проєкт

Мета проєкту: допомогти партнерам краще розуміти власні сексуальні потреби та потреби одне одного, безпечніше говорити про секс, знаходити причини розбіжностей у бажанні та поступово покращувати емоційну й сексуальну близькість. Додаток не замінює сексолога, психотерапевта чи лікаря, а допомагає з психоедукацією, саморефлексією та комунікацією.

Цільовий користувач: дорослі 18+, які перебувають у романтичних або сексуальних стосунках і стикаються з труднощами на кшталт різного рівня лібідо, зниження сексуального бажання, рутини, сорому говорити про секс, незадоволеності сексуальним життям або емоційного дистанціювання.

## Базові можливості

- 💬 AI-сексолог — допомагає структурувати запит і пропонує запитання або вправи.
- 👫 Профіль пари — окремі відповіді партнерів про сексуальні потреби.
- 🔥 Sexual Compatibility — порівняння бажань, частоти, ініціативи та кордонів.

- ❤️ Intimacy Check-in — оцінка бажання, задоволеності та близькості.
- 🧩 Couple Exercises — вправи для комунікації й тілесного контакту.
- 📊 Insights — динаміка емоційної та сексуальної близькості.

## Запуск

1. Створіть віртуальне середовище та встановіть залежності:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Скопіюйте приклад змінних середовища, вставте токен від [@BotFather](https://t.me/BotFather) та рядок підключення з Neon:

```bash
cp .env.example .env
```

У `.env` мають бути рядки `BOT_TOKEN=...` та `DATABASE_URL=...`. Секрети не зберігайте в коді, не комітьте `.env` і не додавайте їх до логів.

3. Запустіть бота:

```bash
python app/main.py
```

4. У Telegram відкрийте бота й надішліть `/start`. Має прийти коротке привітання.

## Перевірка підключення до Neon

Після заповнення локального `.env` перевірте доступність бази через Docker:

```bash
docker compose run --rm db-check
```

Скрипт виконує асинхронний `SELECT 1` через SQLAlchemy та `asyncpg` і виводить лише статус підключення — без `DATABASE_URL`, пароля чи інших секретів. Код завершення `0` означає успішне підключення, `1` — що база недоступна або змінна не налаштована.

## Admin API

Запустіть read-only API для майбутньої web-адмінки:

```bash
docker compose up api
```

FastAPI Docs доступні за адресою `http://localhost:8000/docs`.

- `GET /api/transactions` повертає безпечну історію дій користувачів.
- `GET /api/summary` повертає кількість користувачів, створених пар і дій.

API читає `DATABASE_URL` лише на backend. Frontend ніколи не отримує рядок підключення до Neon.

## React admin dashboard

В окремому терміналі запустіть FastAPI, а потім React-адмінку:

```bash
docker compose up api
cd admin
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай `http://localhost:5173`). Адмінка отримує дані лише через `/api/transactions` і `/api/summary`; Vite передає ці запити на FastAPI локально.
